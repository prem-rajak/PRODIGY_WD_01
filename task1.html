INTERACTIVE WEB DESIGN

A navigation menu that reacts to you.

Scroll down and watch the menu change color. Hover over any menu item to see it light up.

Start scrolling ↓
ABOUT

Simple, smooth and interactive

This project uses HTML for the structure, CSS for the design and JavaScript for the interaction. The menu stays fixed at the top, so it is always visible while you scroll.

FEATURES

What does the menu do?

✦

Hover effect

A menu item changes its background and text color when the mouse is over it.

↕

Scroll effect

The navbar turns dark after you scroll, and the current section is highlighted.

▣

Responsive

On a phone the menu collapses into a ☰ button that opens and closes.

PROJECT

Made with the basics.

No libraries or frameworks were used. Everything is written with plain HTML, CSS and JavaScript.
